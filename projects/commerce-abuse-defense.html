The Problem

eCommerce platforms face constant automated attacks: card-testing bots validate stolen credit cards through checkout flows, scraper bots from datacenter ASNs pollute analytics, and hidden product exploits target $0/warranty products via direct URL. Existing defenses (Shopify native fraud tools, third-party bot mitigation) provide per-order risk scores but lack aggregate abuse pressure measurement.

CAD fills this gap by computing an Abuse Score (0-100) from multiple data sources, then auto-generating deployable WAF rules from the analysis.

Detection Rules

RuleIDSignalSeverity
High-Frequency RequestsCAD-001>N events from same IP in M minutesHIGH

Payment Failure SpikeCAD-003Failure rate above baseline (card-testing)CRITICAL
Session ExplosionCAD-004Sudden increase in unique sessionsMEDIUM
Anomalous User-AgentCAD-005Bot UAs, headless browsers, missing UAMEDIUM
Geo/ASN ConcentrationCAD-006Datacenter ASN traffic patternsLOW-MEDIUM

Each rule produces results with severity and confidence scores. The scoring engine applies configurable weights per category to compute a composite Abuse Score.

Guardrail Generator

CAD converts abuse analysis into deployable WAF rules for both Cloudflare and AWS WAF v2:

Threat SeverityAction
CRITICAL (confirmed attacker IPs)Block
HIGH (bot user-agents)Managed Challenge / CAPTCHA
MEDIUM (datacenter ASN + checkout)JS Challenge / Count
LOWLog only
 
# Generate Cloudflare WAF rules
cad guardrail --source shopify --platform cloudflare --format commands

# Generate AWS WAF v2 rules
cad guardrail --source shopify --platform aws_waf --format json

# Continuous monitoring with alerts
cad watch --source shopify --interval 30m --threshold 25

Attack Chain Research

Phase 3 of the project documents real attack patterns observed in production:

  • 001: Hidden Product Card-Testing -- How attackers discover $0 products via API enumeration and use them for card validation. Includes attack economics, detection signatures, and defense playbook.
  • 002: App-Layer Defense Bypass -- Why client-side bot mitigation (JS fingerprinting, CAPTCHA) is necessary but insufficient. Analyzes 5 bypass techniques and the case for multi-layer defense.
